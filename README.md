# Code for the paper "Secret mixtures of experts inside your LLM"

The pipeline to reproduce the results is in 3 ipython notebooks, which should be run in order.

In all notebooks, there is a `curr_dir` variable and a `scratch_dir` variable defined at the beginning that should be changed to the location of the code and the location where you want to save the datasets, respectively.

 (The results in this paper are already precomputed and cached in this repository, so you can skip to Step 3 if you don't want to run new results.)

1. Run `NOTEBOOK1_generate_activation_datasets.ipynb` and run the python commands generated by this notebook. This creates and saves the activation datasets by feeding forward text data through the pretrained LLMs.

2. Run `NOTEBOOK2_generate_gaussian_datasets.ipynb` and run the python commands generated by this notebook. This creates the Gaussianized datasets corresponding to the saved activation datasets from the previous part.

3. Run `NOTEBOOK3_distill_to_moe.ipynb` and run the SLURM commands generated by this notebook. This runs the distillation jobs from MLP to MoE for the various architectures and reproduces the plots in the paper.
